Leerer Zustand einer Seite oder eines Chats, zentriert mit `space-16` Abstand nach oben. Icon-Kreis 40 px in `brand` 10 % mit einem 20 px Lucide-Icon in `brand`, Überschrift `heading`, ein Satz `body` in `muted-foreground` bis 448 px breit, darunter mit `space-2` Abstand der eine Hauptbutton.
