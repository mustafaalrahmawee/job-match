Bestätigungsdialog für Umbenennen und Löschen, als natives dialog-Element mit dunklem Schleier (schwarz 40 %, leicht unscharf). Breite `content-narrow` (384 px), Fläche `background`, `border`, `radius-xl`, `shadow-xl`, Innenabstand `space-5`, Lücken `space-4`. Titel `dialog-title` als Frage, Text in `muted-foreground` sagt, was verloren geht und was bleibt. Rechts unten Abbrechen (Outline) und die Aktion (Primär, bei Löschen Destruktiv); Fehler erscheinen als Zeile in `destructive` über den Buttons. Escape und Klick auf den Schleier brechen ab. Der Nutzer liefert Titel, Button-Text, Inhalt und die beiden Handler.
