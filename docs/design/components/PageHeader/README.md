Kopfzeile jeder Seite im Inhalt. Höhe `header` (56 px), unten 1 px `border`, Innenabstand `space-4`. Links der Knopf zum Öffnen der Seitenleiste (nur sichtbar, wenn sie nicht angeheftet ist), dann der Seitentitel in `body-medium` als h1, rechts höchstens ein oder zwei Geist-Buttons in `control-sm` mit Icon und Text; der Text verschwindet unter 640 px. Der Nutzer liefert Titel und die Aktionen im Slot.
