Eingabefeld mit Label darüber, für Login, Umbenennen, Zielrolle und eigene Stellen. Label in `body-medium`, `space-2` Abstand zum Feld, Feld volle Breite, Höhe `control`, Rahmen `input`, Fläche `background`, Ecken `radius-md`, `shadow-xs`. Fokus: Rahmen `ring` plus 3 px Ring `ring` 50 %. Select sieht aus wie ein Feld. Der Nutzer liefert Label, Typ, Autocomplete und das Modell; Pflichtfelder sind immer required, Fehler stehen nicht am Feld, sondern als Alert über dem Formular.
