Karte für einen Abschnitt mit Titel, auf allen Seiten mit Inhalt (Lebenslauf, Stellen, Bewerbungen). Fläche `card`, 1 px `border`, `radius-xl`, `shadow-sm`, Innenabstand `space-4`, Lücke zwischen Karten `space-4`. Titel in `section-title` als h2, Inhalt in `body`, Nebenzeilen in `muted-foreground`. Chips (Kenntnisse) sind `secondary` mit `radius-full` in 12 px. Keine farbigen Ränder, keine Icons im Titel. Listen-Karten (Versionen) haben nur `space-2` Innenabstand und Zeilen mit Hover `accent`.
