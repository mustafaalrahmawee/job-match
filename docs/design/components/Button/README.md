Buttons lösen eine Aktion aus; pro Ansicht gibt es genau einen Hauptbutton. Varianten: Primär (`primary`, für Anmelden, Bestätigen, Senden), Outline (`background` mit `border`, für Abbrechen und Zweitaktionen), Geist (nur Text in `muted-foreground`, Hover `accent`, in der Kopfzeile und für Icon-Buttons), Destruktiv (`destructive`, nur für Löschen im Dialog). Höhe `control` (36 px), kleine Variante `control-sm` (32 px) in Kopfzeile und Fehlerboxen. Ecken `radius-md`, runde Icon-Knöpfe (Senden, Stopp) `radius-full`. Text ist ein Verb im Infinitiv in `body-medium`; während einer Aktion deaktiviert mit „…“. Icon-Buttons ohne Text tragen `aria-label` und `title`. Der Nutzer liefert Text und Handler; die Komponente liefert Hover (90 % Deckkraft), Fokusring und deaktivierten Zustand (50 %).
